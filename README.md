CSS Club Chatbot Assets

Public image assets used by the CSS Club Dialogflow chatbot (event posters, logos, etc.).

Images here are referenced via their Raw GitHub URL inside Dialogflow intent responses (Custom Payload), so the chatbot can display them on the website.

Folder structure
events/   → event posters (e.g. abacus-poster.png, css-olympics-poster.png)
logos/    → club logo and branding images
How to add a new image
Click Add file → Upload files on this repo
Upload into the correct folder (e.g. events/your-event-poster.png)
Commit the change
Click the uploaded image → click Raw → copy the URL
Paste that URL into the relevant Dialogflow intent's Custom Payload response
Example Raw URL format
https://raw.githubusercontent.com/Scimath123/css-chatbot-assests/main/abacus.jpeg
